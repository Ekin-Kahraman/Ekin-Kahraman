## [RustScenic](https://github.com/Ekin-Kahraman/rustscenic)

**Built to be the simplest, fastest software for studying gene regulation in single-cell data.**

Creator and maintainer. **Rust and Python.**

Supervised by
[Kuan-Lin Huang](https://www.linkedin.com/in/kuanlinhuang) at the
[Huang Lab at Mount Sinai](https://labs.icahn.mssm.edu/kuanhuanglab/).

**Scale — 1.3 million cells in under 47 minutes**<br>
Gene-network inference using 16 CPU cores on the [IFB Core Cluster](https://doc.cluster.france-bioinformatique.fr/). Resource generation scaled with Mount Sinai’s [Minerva supercomputer](https://labs.icahn.mssm.edu/minervalab/). [Benchmark](https://github.com/Ekin-Kahraman/rustscenic/blob/0c8eb00539e3860c78e452c8661cc2735c169386/validation/scaling/IFB_REAL_RNA_GRN_2026-08-28.md#cell-count-scaling-on-all-1306-million-cells).

**Efficiency — 3.3× faster, 81% lower peak memory**<br>
Compared with arboreto in a matched 20,000-cell gene-network benchmark. [Matched comparison](https://github.com/Ekin-Kahraman/rustscenic/blob/0c8eb00539e3860c78e452c8661cc2735c169386/validation/scaling/IFB_REAL_RNA_GRN_2026-08-28.md#same-node-rustscenic-versus-arboreto).

**Open resource — 704 human cell labels**<br>
Public single-cell data → [reusable exploratory gene networks](https://github.com/Ekin-Kahraman/rustscenic#cellxgene-census-derived-resource).
